# Captions and on-screen copy

Copy is what gets rewritten most. The screen is usually right the first time; the sentences take three tries. Work in this order.

## 1. Collect evidence from three layers

| Layer | What you learn | Where |
|---|---|---|
| UI text | What the feature calls itself: labels, buttons, messages | The app's templates / components |
| Product docs | What happens automatically and what the user still does | Help center, README, specs |
| Real questions | Where users get stuck, in their own words | Support inbox, issues, chat logs |

- Take the **kind** of problem from real questions, never the wording, names or numbers
- Make videos for the questions asked most often first

## 2. Patterns

| Slot | Pattern | Example |
|---|---|---|
| Intro | The problem in one line, ending with "?" | Still copying invoice totals into a spreadsheet? |
| Scene caption | What the screen is doing now, one line, **one bold phrase** | Totals are **calculated for each month** |
| Ending | The result the feature gave | Upload the file. The numbers fill themselves. |

One line per caption. If it needs two lines, the scene is doing two things; split it.

## 3. Avoid

| Avoid | Why | Instead |
|---|---|---|
| "...and you're done" | Reads as the whole task finishing when the user still reviews and submits | "...is filled in" |
| "No more manual work" | There is usually a manual fallback when detection fails | "When recognised, it fills in automatically" |
| Words that clash with a menu name | If the UI has a "Manual entry" menu, "don't enter manually" confuses | Use a different verb |
| Counts and percentages (users, accuracy) | They change and the video cannot | Leave out, or put in the description with a date |
| Real customer names | Consent and privacy | Made-up names |

## 4. Five checks before rendering

1. Is what the caption says **visible in that scene**?
2. Does it suggest the product does something the user still has to do (review, confirm, submit)?
3. Does any word clash with a label on screen?
4. Any real number, name or organisation?
5. If a step is faked for filming, does the caption state it as fact?
